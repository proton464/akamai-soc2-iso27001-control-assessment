# Diagrams

Architecture and data-flow diagrams for the control assessment.

## Files
- **[sample-cloud-architecture.drawio](sample-cloud-architecture.drawio)** — High-level sample cloud workload architecture showing users, CDN/WAF, load balancer, web/app tier, API services, database, object storage, plus callouts for IAM, logging, and vulnerability management. This is the primary diagram for the assessment scope.

### How to view / edit
1. Open [diagrams.net](https://app.diagrams.net) (or the Draw.io desktop app).
2. File → Open From → Device (or GitHub) and select `sample-cloud-architecture.drawio`.
3. Edit as needed, then export to PNG for portfolio screenshots (File → Export As → PNG).

**Suggested additional diagrams (optional):**
1. Data-flow diagram highlighting encryption and logging points
2. Simple control testing workflow

Export final versions as PNG and reference them from the main README and control matrix so reviewers can see them quickly.
