# Control Matrix Guidance

Build this in Microsoft Excel or Google Sheets.

## Recommended Columns
- Control ID
- Control Name
- Control Description
- SOC 2 Criteria (e.g., CC6.1, CC7.2)
- ISO 27001 Annex A Reference (e.g., A.5.15, A.8.15)
- NIST / Other Mapping (optional)
- Implementation Summary
- Evidence Required
- Test Procedure
- Test Result (Pass / Fail / Partial)
- Observations / Gaps
- Remediation Owner
- Status

## Suggested Controls to Include (8–12)
1. Access Control / IAM (least privilege, MFA)
2. Encryption at Rest
3. Encryption in Transit
4. Logging and Monitoring
5. Change Management
6. Vulnerability Management
7. Incident Response (high-level)
8. Backup and Recovery
9. Network Segmentation / Security Groups
10. Vendor / Third-Party Risk (lightweight)

## Tips
- Use data validation for Test Result and Status.
- Add conditional formatting (green/yellow/red).
- Include a summary dashboard tab with pass rate and open gaps.
- Reference free CIS Benchmarks or public cloud security guidance for realistic implementation language.
