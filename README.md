# SOC 2 / ISO 27001 Control Assessment & Evidence Package for a Cloud Workload

**Portfolio Project** | Demonstrates security control evaluation, audit evidence collection and organization, control testing, and gap identification against SOC 2 and ISO 27001.

## One-Sentence Elevator Pitch
A complete control assessment workbook and evidence repository that demonstrates how to evaluate security controls against SOC 2 and ISO 27001, collect audit-ready evidence, and identify gaps for a sample cloud environment.

## Business / Security Outcome
Produces audit-ready evidence, clear control testing results, and prioritized gaps so engineering and compliance teams can demonstrate operating effectiveness and drive remediation.

## Tech Stack
- Microsoft Excel or Google Sheets — control matrix, testing log, and gap tracker
- Markdown + GitHub — evidence index and narrative
- Draw.io / diagrams.net — architecture and data-flow diagrams
- Snagit — annotated evidence screenshots
- Free public references (CIS Benchmarks, framework control language)

## Key Features / Deliverables
- [ ] Control assessment matrix (8–12 controls mapped to SOC 2 and ISO 27001)
- [ ] Sample evidence artifacts and evidence index
- [ ] Control testing results log
- [ ] Gap log with remediation recommendations
- [ ] Architecture diagram of the assessed environment
