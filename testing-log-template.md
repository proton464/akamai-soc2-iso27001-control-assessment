## Example Test Procedure Language
- **Access Control:** Reviewed IAM policies for least privilege; verified MFA enforcement on privileged roles; sampled 5 user accounts.
- **Logging:** Confirmed logging enabled on critical services; reviewed retention settings; inspected sample log events for required fields.
- **Encryption:** Verified encryption at rest settings; confirmed TLS configuration on public endpoints.

Document both the procedure and the actual result so a reviewer can see operating effectiveness testing.
